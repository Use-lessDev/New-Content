# New Content (Java)

Java conversion of the New Content Mindustry mod. Original mod by Rylid Umil and Aegires; Java source and build instructions are included.

## Source
- `src/newcontent/NewContentMod.java` — Java entry point and vanilla content patches.
- `mod.hjson` — mod metadata and content order.
- `build.sh` — build helper; set `MINDUSTRY_JAR` to your Mindustry JAR (version 154 or newer).

The mod's content assets (content definitions, sprites, maps, schematics and audio) are part of the distributed JAR and still need to be included in the repository source tree for a complete source build.
